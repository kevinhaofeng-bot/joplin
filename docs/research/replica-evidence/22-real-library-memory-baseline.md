## 隔离与方法

- 从既有导入测试库克隆至`/tmp/joplin-product-memory.yUAOJC/profile`，原库不写入。
- SQLite核对1666篇笔记、4153条资源记录，目录约1.2GiB。
- Apple M3 Max 48GiB，macOS14.7.2。
- 运行既有measure-product-memory.sh，三次分别启动同一候选包，各等待10秒，记录ps RSS与footprint。每次仅终止脚本启动的测试进程。
- 日志和样本位于上述临时目录results/；不是持续绘制/输入性能测试，未设定200块10图与50可见卡片负载。
