# Joplin Lite 0.7.2 个人自用交付验收

日期：2026-10-08

结论：**接受为个人自用 MVP 交付版**。这不是“完整复制 Evernote 全部功能”的声明；它表示当前正式安装版的核心笔记工作流、迁移、保全、搜索和 NAS 同步已经具备可日常使用的闭环。

## 本轮高价值实机结果

### 1. 全量迁移

- 使用当前候选通过 GUI 导入原始 1.17 GB JEX。
- 结果：1667 篇笔记、31 个笔记本、64 个标签、425 条笔记标签关系、4153 个资源记录。
- 4127 个实际资源文件逐个与数据库记录校验，大小和 SHA-256 全部一致；SQLite integrity 为 `ok`，外键违规为 0。
- 67 篇不支持的旧格式按产品策略降级为可读正文，原始 body/item 字节保存在导入审计表，不静默丢弃。
- 实机打开普通图文笔记“日本驾照两个密码”：标题、正文、缩略图和原图均直接显示；图片后台文字提取提示可见。
- 实机打开降级样本：正文和链接可读、可搜索；不支持的外部图片语法以原文本保留。

### 2. 备份和恢复

- 通过正式 UI 创建完整资料库备份，manifest 中数据库 SHA 与实际文件一致。
- 源库与备份库 66 张表双向内容差异为 0；integrity 为 `ok`，外键违规为 0。
- 通过正式 UI 恢复为新资料库并实际打开；除新设备安全要求清空 `sync_outbox` 外，其余 65 张表逐表一致。
- 当前资料库未被恢复操作覆盖，没有遗留 `.restore-*` 暂存。

### 3. NAS 同步和故障安全

- 当前正式资料库：24 篇笔记、14 个资源；outbox、inflight、永久失败和未处理冲突均为 0。
- 界面显示“已同步：上传 0、下载 0”。独立 HTTPS 拉取游标 46 返回 HTTP 200、0 条新变更、next cursor 46。
- 既有相同 `sync.rs` 已真实通过：双客户端离线编辑与重开收敛、软删除对离线编辑保留冲突副本、48 MB 附件上传中断续传、NAS 服务备份恢复后新客户端取回、ACK 丢失幂等、游标原子推进、下载范围中断续传和全部哈希校验。

### 4. 正式安装生命周期和搜索

- 从 `/Applications` 正常退出并重开后，63 张受保护业务表逐表哈希零变化；24 篇笔记、14 个资源及游标 46 保持；同步队列仍全部为 0。
- 重开约 30 秒 RSS 为 55.8 MB；此前全量 JEX 导入期间观察峰值约 124 MB，导入完成约 120 MB。
- 正式版搜索 `NAS228` 在包含截图等待的 413 ms 内显示 12 条结果；按 Enter 打开正确笔记和 2.5 MB 附件卡。

## 交付边界

- 当前结论是“可以作为个人自用版本交付”，不是“Evernote 所有功能和像素级体验全部复制完毕”。
- 67 篇降级笔记仍属于兼容性提示，不是无损视觉还原；其原始内容已保留，可后续逐类增强转换。
- 不再把动画帧率、极端组合输入、全部媒体格式等细项作为本次个人自用 MVP 的阻断项；后续改进不得破坏已通过的保存、图片、备份、迁移和同步稳定链。
